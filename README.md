Lfd Resource Editor (LRE) will eventually be the all-in-one editor for the 
Lucasarts .LFD resource file format, most notably used by the X-Wing series.

This is just getting started, and will likely be canibalizing some of my other editing
tools.  As time goes on, those separate tools may be deprecated as the features get
incorporated.

## Install
LRE does not use an installer, simply download the latest ZIP file from the
[Releases](https://github.com/MikeG621/YOGEME/LfdResourceEditor) page on Github and
extract to your location of choice.

LRE does not require any platforms to be installed, as this is intended to edit the
files as-is. There will be some limitations or oddities because it's operating in
isolation, and I'll supply some default to smooth that out, but many LFD files weren't
designed to be looked at in isolation, but within the context of the game, working
with other files.

## Uninstall
To remove LRE, simply delete the directory where you placed it.
Currently, there are no other settings/config files.
